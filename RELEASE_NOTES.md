# Panelbook 0.4.1

The Windows portable launcher now closes its minimized CMD window after **Close server when all tabs close** shuts down Panelbook. The server previously exited normally while the window remained open.

The hosted package now uses `compose.yaml`. `README-HOSTING.md` includes the complete Compose example, plus Proxmox, NGINX, HTTPS, backup, and update instructions.

Both `Panelbook-Portable-v0.4.1.zip` and `Panelbook-Server-v0.4.1.zip` are included. The Windows updater selects only the portable ZIP.

Windows versions 0.3.3 and newer can install this update in the app. Versions 0.2.0 through 0.3.2 require the manual update described in README.md.
