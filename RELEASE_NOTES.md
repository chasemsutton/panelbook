# Panelbook 0.5.0.8

Fixed mobile printing and PDF output. Phone card layouts and sort controls now apply only on screen, so printed panel directories and circuit / point detail tables keep their full-width columns, borders, and breaker row spans. Printed pages use a white background.

Existing accounts and data remain in the `panelbook-data` volume. In Arcane, redeploy the project to pull the updated image.

The Windows and hosted packages are `Panelbook-Portable-v0.5.0.8.zip` and `Panelbook-Server-v0.5.0.8.zip`.
